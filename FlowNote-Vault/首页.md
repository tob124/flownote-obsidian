# FlowNote · 随手记与回顾

这是使用虚构示例记录的 Obsidian 原型库。启用 FlowNote Assistant 后，点击左侧 ✦ 或打开命令面板搜索 `FlowNote Assistant`。

| 想做什么 | 从哪里开始 |
|---|---|
| 随手记 | 运行「随手记」。输入原话，标题可以留空。 |
| 整理一条 | 打开一条收件箱笔记，运行「整理当前笔记」。 |
| 查某个主题 | 打开 [[主题/实验设计]] 或 [[主题/观点复盘]]。 |
| 做一次 Dream | 运行「运行 Dream 回顾」，输入「怎样从失败样本完善评价指标」。 |
| 看原始记录 | 打开下面的索引，或在文件列表里进入「收件箱」。 |

## 目录

- **收件箱**保留原始记录和各自的整理属性。
- **主题**按主题浏览笔记。添加主题时，在这个目录下创建同名笔记。
- **回顾**保存每次生成的 Wiki 和 Dream。可以编辑，也可以把内容整理成自己的文章。
